# Quantum Hands

## Overview

Quantum Hands is a browser-based interactive hand-tracking visualization built using HTML, CSS, JavaScript, and MediaPipe Vision Tasks. The application uses a webcam to detect hand landmarks in real time and renders dynamic visual effects on an HTML5 canvas.

This project was recreated as a learning exercise inspired by existing hand-tracking visualizations. The interface and visual experience were customized by adding multiple themes and enhancing the animation effects.

---

## Features

* Real-time hand tracking using MediaPipe
* Detection of up to two hands simultaneously
* Interactive fingertip glow effects
* Pinch gesture visualization
* Dynamic energy ribbon animations
* Multiple visual themes:

  * Toxic
  * Fire
  * Ice
  * Rainbow
* Responsive full-screen interface

---

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6 Modules)
* HTML5 Canvas API
* MediaPipe Vision Tasks
* Web Camera API

## Getting Started

### Prerequisites

* A modern web browser (Google Chrome, Microsoft Edge, or Firefox)
* Webcam access
* Internet connection (required to load MediaPipe resources from the CDN)

### Running the Project

1. Clone this repository.

```bash
git clone https://github.com/your-username/quantum-hands.git
```

2. Open the project folder.

3. Launch `index.html` in your browser.

4. Allow camera permissions when prompted.
